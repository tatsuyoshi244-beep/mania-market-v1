# 作業前後の確認手順

## 必須ルール

1. 作業前に、GitHub `main`、Vercel本番コミット、対象コードの3点を照合する。
2. 外部サービスが発行したURLや環境変数は、根拠なく削除・補完・正規化しない。
3. 修正後は、型検査・Lint・本番ビルドだけで完了扱いにしない。
4. Vercel本番の `/api/health` でDBとAuthがともに `ok`、かつ想定コミットが稼働していることを確認する。
5. 認証変更は、画面表示、Auth到達性、登録・ログインの順に確認する。利用者に同じ操作を繰り返させない。

## 2026-09-13 Neon Auth障害

- 事象: 新規登録が「登録処理に接続できませんでした」で失敗した。
- 原因: NeonのProject Infoが発行した完全なAuth URLから、必要な末尾パスをコード側で削除した。
- 修正: `NEON_AUTH_BASE_URL` は末尾の `/` だけを除き、それ以外のパスはそのままSDKへ渡す。
- 再発防止: `/api/health` は環境変数の有無だけでなく、Neon Authの `get-session` へ実際に到達できるかを確認する。
